NETGO PUBLIC WEBSITE — DEPLOYMENT NOTES

This is a static public demo prepared for Vercel hosting.
It does NOT include a real AI model, user accounts, or image generation yet.

PUBLISH:
1. Put this folder in a GitHub repository you control.
2. Sign in to Vercel using that repository provider.
3. Choose Add New -> Project and import the NETGO repository.
4. Framework Preset: Other. Build Command: leave blank. Output Directory: ./
5. Deploy. Vercel will provide a free *.vercel.app address if available.

A trusted adult may need to help with account creation or hosting terms.
Never place API keys or passwords in index.html or a public repository.
Real AI requires a secure backend and a provider or compatible local model.
Cloud AI is not guaranteed unlimited or free.
